## 概要

BtoB営業担当者向けの企業リサーチ支援アプリです。

Google Places API (New) を利用して実在企業を検索し、企業情報の確認、AIによる企業要約、営業メールの生成までを一つの画面で行えます。

---

## 主な機能

- Google Places API (New) による実在企業検索
- キーワード・地域・業種・従業員数以上で検索
- 企業一覧表示
- 企業詳細表示
- Google Maps・公式サイトへのリンク
- AI企業要約
- AI営業メール生成
